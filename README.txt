AD01 - FUNDAMENTOS DE DESARROLLO WEB
Taller de mantenimiento automotriz

COMO ABRIR EL PROYECTO
1. Abre index.html en Chrome, Edge o Firefox.
2. Presiona "Ingresar" e inicia sesion con una de las cuentas de abajo.
3. El cliente puede registrar y consultar sus mantenimientos.
4. El administrador puede ver, editar y eliminar solicitudes, y cambiar su estado.

NOTAS
- Las cuentas son ficticias, creadas para realizar las pruebas del deber.
- Los mantenimientos se guardan en el navegador mediante localStorage.
- No se necesita instalar programas ni configurar una base de datos.
- Para cargar la foto y las ventanas de SweetAlert2 se necesita Internet.
